# Plogy · Brand kit 01

Abre index.html para consultar la guía visual local. No requiere instalar dependencias.

## Assets

En assets/: siete versiones SVG con letras convertidas a curvas y catorce PNG en 1024 y 4096 px. plogy-color y plogy-white son logos con esfera en color y fondo transparente. plogy-black y plogy-mono-white son monocromáticos transparentes. light-background y dark-background incluyen fondo. plogy-symbol contiene la esfera sola. Todos incluyen margen de protección.

## Implementación

Importa tokens.css o consume tokens.json. Los selectores plogy-button, plogy-glass y plogy-field no dependen del servidor del sitio. Configura tu @font-face con una versión licenciada de Screener Bold; el CSS de componentes no incluye archivos de fuente. La guía HTML contiene la fuente demo suministrada solo para revisión.

## Fuente y uso

La fuente disponible declara FONTSPRING DEMO. No se ha verificado una licencia comercial, de logo o web. Los SVG y PNG se derivan de esa misma fuente; convertirla a curvas no sustituye la licencia. Antes de usar en producción, verificar derechos y regenerar si la versión licenciada cambia los trazados. No se presenta el paquete como una licencia de marca o tipografía.

## Alcance

Colores, logo y tipografía se basan en el sitio actual. Área de protección y mínimos son propuestas. El botón naranja usa tinta para mejorar contraste; este cambio vive solo en el kit. El motor líquido sigue en el sitio. No se hicieron cambios de Git ni despliegues.
