Cómo pedir una web con seis campos · versión 2026-10-20 · borrador
El brief

Seis campos. Cada uno cierra una adivinanza.

1

Objetivo¿Qué debe lograr la web para el negocio?Sin él, nadie sabe qué es un éxito.

2

Audiencia¿Quién entra y qué quiere resolver?Sin ella, se escribe para nadie.

3

Oferta¿Qué ofreces, dicho en una frase?Sin ella, la web decora y no vende.

4

Prueba¿Qué evidencia real tiene el negocio?Sin ella, todo suena a promesa.

5

Acción principal¿Qué debe hacer quien entra?Sin ella, hay diez botones y ninguno manda.

6

Restricciones¿Qué plazo, presupuesto y límites hay?Sin ellas, aparecen tarde y cuestan más.

Criterio de Plogy. Método propuesto, no una norma ni un estudio.

5. Acción principalQuien entra debe [una sola acción].

Criterio de Plogy. Una frase por campo. Si un campo queda vacío, anótalo como tarea pendiente.
Después de publicar

El brief también es el examen.

Oferta¿Se entiende qué ofreces de un vistazo?
Audiencia¿Habla con las palabras de quien entra?
Prueba¿La evidencia está a la vista?
Restricciones¿Se respetaron plazo, presupuesto y límites?
Acción principal¿Cuántas personas hicieron la acción?
Criterio de Plogy. La cuenta de la acción depende de cómo se registre (botón, mensajes, formularios). Esta guía no explica la medición técnica.
