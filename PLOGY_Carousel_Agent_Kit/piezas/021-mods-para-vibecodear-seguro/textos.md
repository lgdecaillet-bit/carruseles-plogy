## Post de LinkedIn

Mucha gente está construyendo software con Claude Code sin saber programar. Está bien. Lo que no está bien es hacerlo sin frenos.

Claude Code ejecuta comandos en tu computador. Puede borrar una carpeta, pisar un repositorio con un force push o tocar el archivo donde guardas tus claves.

Desde octubre, Claude Code tiene Mods: pequeños programas que se meten entre Claude y lo que hace. Cinco que recomendamos a quien empieza:

1. blast-radius (ejemplo oficial de Anthropic): retiene comandos riesgosos y te deja decidir.
2. /diff (ya viene incluido): muestra los cambios antes de seguir.
3. replay-theater (ejemplo oficial): recorre lo que Claude editó en su último turno.
4. Un guardián de claves que no deje tocar tus archivos .env (se lo pides a Claude).
5. Una confirmación antes de cada push a main (la documentación trae un ejemplo casi igual).

Una advertencia: un Mod corre con tus permisos. Instala solo de fuentes de confianza.
