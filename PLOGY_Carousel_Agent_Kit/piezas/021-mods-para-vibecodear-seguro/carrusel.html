Borra una carpetay no hay papelera de reciclaje.

push --force
Toca tus claveslas de tu base de datos o tu pago.

Un Mod se mete entre Claude y la acción: la mira, la cambia o la frena.

06/07

Cómo probar los de ejemplo.

1
Descarga los ejemplosgit clone https://github.com/anthropics/claude-code-playground
2
Prueba uno en una sesiónclaude --plugin-dir ./claude-code-playground/claude-code/mods/blast-radius
3
Para dejarlo instalado/plugin marketplace add ./claude-code-playground/claude-code/mods /plugin install blast-radius@claude-code-playground-mods
Ojo: un Mod corre con tus permisos.Instala solo de fuentes de confianza. Antes, revisa qué hace con claude plugin validate. Para apagarlos, claude --safe-mode.
Requiere Claude Code 2.1.287 o superior. Fuente: documentación de Claude Code.
