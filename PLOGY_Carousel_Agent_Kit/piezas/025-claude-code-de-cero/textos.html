Post de LinkedIn

Claude Code no es solo para programadores. Funciona en cualquier carpeta: reportes, documentos, notas.

Lo básico para empezar:

  1. Primero el plan. Con Shift+Tab entras en modo plan: Claude lee y propone, sin tocar nada, hasta que apruebas.
  2. Un CLAUDE.md con tu contexto: de qué es el proyecto, cómo trabajan y qué no se hace nunca. El comando /init arma un primer borrador.
  3. Skills para lo que repites: una carpeta con un SKILL.md que Claude carga cuando hace falta.
  4. MCP para conectarlo a tus herramientas. Conecta solo lo que la tarea necesita.
  5. Permisos y frenos: tú decides cuánto hace sin preguntar.

Nuestro criterio: la herramienta se aprende en una tarde. Lo que se entrena es saber qué encargarle y revisar lo que vuelve.

Armamos una guía de primeros pasos para quien quiera empezar. Escríbenos y te la mandamos.
