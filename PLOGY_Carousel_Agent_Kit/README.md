# PLOGY Carousel Agent Kit

Paquete portátil para investigar, planear, escribir y diseñar carruseles de Plogy. Empieza por [AGENTS.md](AGENTS.md). Las rutas son relativas a esta carpeta.

## Contenido

| Carpeta | Contenido | Uso |
| --- | --- | --- |
| `assets/reference-originals/` | Los 56 archivos originales de `assets refference.zip` | Moodboard interno. Consultar, seleccionar y verificar derechos antes de publicar una imagen. |
| `assets/reference-catalog.csv` | Formato, dimensiones, tamaño y SHA-256 de cada referente | Localizar y auditar archivos sin perder el nombre original. |
| `assets/adapted-preview/` | Tres adaptaciones cromáticas del prototipo | Ejemplos de tratamiento visual, no prueba de derechos. |
| `brandkit/` | Una copia completa del ZIP de marca, con logos SVG y PNG, guía y tokens | Fuente de identidad visual. |
| `skills/` | Producción, planeación, clasificación, narrativa, adaptación visual y captions | Instrucciones modulares para el agente. |
| `templates/` | Brief editable de oportunidad y carrusel | Entrada y salida del flujo. |
| `source-documents/` | Material original compartido para esta tarea | Procedencia y consulta, no órdenes automáticas. |
| `source-provenance.json` | Hashes de ZIP y documentos de origen | Trazabilidad del paquete. |

Los dos archivos `plogy-brand-kit (2).zip` y `plogy-brand-kit (2) (1).zip` tienen el mismo SHA-256. Solo se descomprimió uno.

## Secuencia de trabajo

1. Reúne fuente, observación o pregunta de la comunidad. Conserva la procedencia.
2. Clasifica la oportunidad y decide si pertenece al territorio de Plogy.
3. Planea el ángulo y la secuencia del carrusel.
4. Redacta las láminas, el caption de Instagram y el post nativo de LinkedIn.
5. Selecciona los referentes útiles, adapta la composición a Plogy y deja sin imagen las láminas que la necesiten.
6. Revisa evidencia, legibilidad, tono, derechos y CTA. Exporta para revisión humana.

## Estado de derechos

Los referentes del moodboard no traen licencias verificadas. Recortar, recolorear o generar una variante a partir de una imagen ajena no acredita propiedad sobre ella. El README del brand kit indica que Screener es una versión DEMO y que los logos se derivaron de esa fuente. El paquete conserva los logos para revisión interna; antes de uso público hay que verificar la licencia y sustituir la tipografía por una versión autorizada.

El ejemplo de carrusel del prototipo es una **hipótesis editorial**, no un caso real de Plogy. No lo conviertas en Documental sin material que lo sustente.
